Live Sync — Teammate Sharing
Setup Instructions
1
Create a new Google Sheet at sheets.google.com. You can name it anything — it just stores the sync state.
2
In the sheet, go to Extensions → Apps Script. Delete any existing code and paste the Luminary Sync Script included in your download package (see README).
3
Click Deploy → New Deployment → Web App. Set Execute As: Me. Set Who Has Access: Anyone. Click Deploy and authorize when prompted.
4
Copy the Web App URL and paste it in the field below. Click Connect.
5
Share the same Web App URL with all teammates. Each person pastes it into their own copy of the app to stay in sync during the event.
